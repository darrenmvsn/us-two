# Learnings

What agents got wrong here, so the next one doesn't. **Read every file in this
folder at the start of a session**; they are short on purpose. Standing rules
live in `AGENTS.md`; an entry here is a lesson with its evidence. Same format
as DesignLoop's, Moatlab's and Viralab's `learnings/`.

Add one entry in the same commit as the work when you were corrected, you
introduced a bug, something failed in a way you did not expect, or a review
finding generalises.

```markdown
- **2026-10-22** One sentence: the lesson, stated as what to do. Evidence: `path::symbol` or a commit sha. Tags: `game`, `tests`
```
